# 🌍 The Living Red List Globe

**살아있는 멸종위기 지도**

전 세계 멸종위기 동물의 서식지 데이터를 3D 지구본 위에 시각화하여, 종의 소실이 특정 지역이 아닌 '지구 전체'의 문제임을 직관적으로 보여주는 인터랙티브 교육 자료입니다.

## 🎯 프로젝트 목표

- **직관성**: 사용자는 지구본을 돌려보며 멸종 위기가 특정 국가가 아닌 '지구 전체'의 문제임을 즉각적으로 인지합니다.
- **심각성 체감**: 멸종 등급을 색상으로 보고, 타임라인을 통해 서식지가 줄어드는 것을 보며 문제의 심각성을 체감합니다.
- **데이터 리터러시**: 학생들은 이 자료를 통해 "어느 대륙에", "어떤 이유로", "얼마나 많은" 종이 위기에 처했는지 스스로 탐구하는 데이터 기반 학습을 할 수 있습니다.

## ✨ 주요 기능

### 1. 3D 지구본 시각화
- Three.js를 활용한 인터랙티브 3D 지구본
- 부드러운 회전 및 줌 인/아웃 기능
- 별과 대기권 효과로 몰입감 증대

### 2. 멸종 등급별 색상 구분
- **EX (멸종)**: 검은색 ⚫
- **EW (야생 멸종)**: 회색 ⚪
- **CR (위급)**: 붉은색 🔴
- **EN (위기)**: 주황색 🟠
- **VU (취약)**: 노란색 🟡

### 3. 인터랙티브 정보 패널
- 동물 클릭 시 상세 정보 표시
- 이름, 학명, 멸종 등급
- 위협 요인 설명
- 서식지 정보
- 남은 개체 수

### 4. 타임라인 기능
- 1900년부터 현재까지의 시간 선택
- 연도별 멸종위기종 변화 추적
- 역사적 멸종 사례 확인

### 5. 필터 및 검색
- **등급별 필터**: 특정 등급의 동물만 보기
- **대륙별 필터**: 지역별 멸종위기종 확인
- **검색 기능**: 동물 이름으로 빠른 검색

## 🚀 시작하기

### 필수 요구사항
- Node.js (v14 이상)
- npm 또는 yarn

### 설치 방법

```bash
# 저장소 클론
git clone <repository-url>
cd endangered-globe

# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 브라우저에서 http://localhost:3000 접속
```

### 빌드

```bash
# 프로덕션 빌드
npm run build

# 빌드 결과 미리보기
npm run preview
```

## 📊 데이터 소스

현재 버전은 샘플 데이터를 사용합니다. 실제 IUCN Red List API를 연동하려면:

1. [IUCN Red List API](https://apiv3.iucnredlist.org/)에서 API 토큰 발급
2. `src/data.js` 파일에서 API 키 설정
3. `fetchFromIUCN()` 메서드를 활성화
